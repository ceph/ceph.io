Ceph's future is planned in public. A new named stable release ships roughly every year, each supported for about two years, and everything that goes into one is proposed, discussed, and tracked in the open.

The current stable release is Tentacle (v20), with the next release, Umbrella, already in development. Each cycle begins at the annual Ceph Developer Summit, where contributors plan the following release component by component, and continues through open developer calls, the public issue tracker, and the project boards below.

See our vision

Where planning happens

  • Ceph Developer Summit

    An annual online summit, named for the release it plans, with recorded sessions for every component. The 2026 summit covers RADOS, RGW, CephFS, RBD, Crimson, and more.

  • Developer calls

    The Ceph Developer Monthly call and the component team meetings are open to everyone. Start on the contribute page or browse the virtual meetings.

  • Mailing lists

    Design discussion happens on the dev mailing list, in the open, with public archives.

  • Issue tracker

    Bugs, features, and backports under development are tracked on tracker.ceph.com.

Component project boards

  • Dashboard

    Work on Ceph's built-in web-based management and monitoring interface.

    Dashboard board

  • NVMe-oF

    The NVMe over TCP gateway: SAN-style block access to RBD for any standard NVMe initiator.

    NVMe-oF board

  • Testing

    Pulpito and Teuthology, the integration testing framework and dashboards that gate every release.

    Testing board

  • Crimson

    The next-generation OSD and its SeaStore backend, being rebuilt for the flash era.

    Crimson board

The backlog

Longer-range plans and feature ideas are collected on the public Ceph Backlog board, where anyone can see what the community is considering next.
