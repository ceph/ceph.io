When will the next Ceph release come out, and how long is each release supported?

Ceph aims to publish a point release of each stable release every 8 weeks, and maintains two stable major releases at a time. When a new major release goes GA, the oldest major gets one more point release and then reaches end of life.

The dates below are estimates, not commitments. They are derived from where each release is in the release process (git tags, release branches, release notes in progress) and from how long each stage has taken historically. Estimates updated {{ eta.generated | formatDate }}.
